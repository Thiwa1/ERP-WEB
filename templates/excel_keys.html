How it works

The workbook sends what you type to this website over HTTPS — the same road your browser uses — and the server writes it to the database. Excel never connects to the database itself, so nothing extra has to be opened on the hosting.

  1. Create a key below for each person or PC that will use the workbook.
  2. Click Download Workbook, then save it as .xlsm (macro-enabled).
  3. Right-click the saved file → Properties → tick Unblock, or Excel will block the macro.
  4. Paste the key into the workbook's Setup sheet, then run TestConnection.
